Steal this

Run the plugins yourself

# once, in Claude Code
> /plugin marketplace add benchlog-ai/plugins
# then any of these
> /plugin install wardrobe-tracker@benchlog
> /plugin install larder@benchlog
> /plugin install footprints@benchlog
> /plugin install gourmet-trails@benchlog

All four are live. Add the marketplace once, then install the ones you want. The first time you use one, Claude makes a fresh private page for it in your own account, empty and ready for your data. Nothing is sent to Bench Log.
